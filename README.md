# PingPongGame

Proyecto final desarrollado en C++ utilizando Qt Framework y CMake.

## Descripción

PingPongGame es un videojuego estilo ping pong que implementa mecánicas de movimiento, colisiones, inteligencia artificial y sistema multimedia utilizando programación orientada a objetos.

---

## Tecnologías utilizadas

* C++
* Qt 6
* CMake
* Qt Multimedia

---

## Características principales

* Movimiento dinámico de entidades
* Sistema de colisiones
* Inteligencia artificial básica
* Gestión de niveles
* Reproducción de audio y efectos multimedia
* Uso de recursos mediante Qt Resource System
